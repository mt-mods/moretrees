# More trees

[![ContentDB](https://content.luanti.org/packages/mt-mods/moretrees/shields/downloads/)](https://content.luanti.org/packages/mt-mods/moretrees/)
[![luacheck](https://github.com/mt-mods/moretrees/actions/workflows/luacheck.yml/badge.svg)](https://github.com/mt-mods/moretrees/actions/workflows/luacheck.yml)
[![Translation status](https://translate.luanti.ch/widget/mt-mods/moretrees/svg-badge.svg?capitalize=1)](https://translate.luanti.ch/engage/mt-mods/)

This mod adds a whole bunch of new types of trees.

Much of the code here came from cisoun's conifers mod and bas080's
jungle trees mod, and big contributions by RealBadAngel.

Brought together into one mod and made L-systems compatible by Vanessa
Ezekowitz.

## Dependencies

- Luanti/Minetest v5.10
- `xcompat`

### Optional

- MTG mods `doors`, `stairs`, `farming`, `default`, and `vessels`
- `moreblocks`
